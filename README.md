## 是什么

827 的 70 个知识点连成一张网：边是关系，点是考点，环是掌握度。
点一个点，右侧展开考点、图卡和题目；**点结点会弹出居中答题层，底层关系图暂停渲染**。

## 面板

1. 一句话考点
2. 真题年份（点年份打开原卷 PDF）
3. 图卡：AOE / AVL / KMP 各 4～5 张静态 SVG，每张配一段解说
4. **题目：直接点选项答题**
   - 选对变绿、选错变红，并标出正确答案
   - 答对会记录；“答对 2 / 3”实时更新
   - **该知识点的题全部答对 → 自动标为「掌握」**（结点环变绿、星图点亮）
5. 掌握度 / 易错
6. 相邻知识点

## 性能相关的几条约定

- 画布**按需重绘**：只有物理在动、或 350ms 内有过交互（拖动/缩放/悬停/选中）才画一帧，静止时 0 CPU。
- **不要给覆盖层加 `backdrop-filter`**：全屏毛玻璃叠在持续重绘的 canvas 上会整屏重算模糊，直接卡死。遮罩已改成纯半透明 + `pointer-events:none`，这样面板打开时滚轮和点结点仍然有效。
- 面板打开时点画布空白处会关掉面板，点另一个结点会直接切过去。
- 字段命名注意：物理布局用 `_chx/_chy` 存章节中心，不要用 `cx/cy`（会和知识点复杂度字段撞车）。
## 卡顿排查记录（2026-11）

现象：点知识点或点题库后界面卡死。逐项排除后改了三处：

1. 遮罩层的 `backdrop-filter: blur()` —— 全屏实时模糊叠在 canvas 上，删掉。
2. 顶栏的 `backdrop-filter: blur(14px)` —— 同样在实时模糊画布顶部，改成实色。
3. 面板打开时画布还在 60fps 重绘 —— 现在卡片一打开就**停画**（只保留刚操作后的 120ms），关闭时再补一帧。

另外：选中结点不再移动相机（卡片是模态的，没必要），DPR 上限降到 1.25、超过 260 万像素的窗口降到 1。
## 性能：画布像素预算

大窗口卡顿的根因是填充率（每帧要画的像素数），不是逻辑死循环。现在的做法：

- **画布最多 420 万像素**（2560×1440 正好 1:1）（`render.js` 的 `PIXEL_BUDGET`）。窗口是 2560×1440 就按 0.74 倍内部分辨率渲染，4K 按 0.5 倍，再由浏览器拉伸到全屏。窗口再大，绘制量也不涨，代价是略糊。
- 网格固定在 CSS 层，不跟随相机（跟随要每帧重写全屏样式，比画布还贵）。
- 交互进行中只画骨架（点 + 边），停手 110ms 后补一帧带标签的完整画面。
- 满 60fps（不再节流）；静止时完全不画。
- **标签不做数量上限**，只靠矩形避让：按 选中 > 悬停 > 邻居 > 高频 > 普通 的顺序抢占位置，重叠的不画。所以密集区也能看到名字。
- 面板在右侧，不再遮挡画布，因此不需要遮罩层。

字段与命名：物理布局的章节中心用 `_chx/_chy`，不要用 `cx/cy`（会覆盖知识点的复杂度字段）。
## 动效

- 点知识点：相机 220ms ease-out 滑到该点，落点是面板左侧可视区的中心（不遮挡、不跳变）
- 面板：右侧滑入 260ms，内容逐块 softIn
- 按钮/芯片：180ms 颜色过渡 + 按下微缩
## 答题弹层

- 点知识点 → 面板在**正中**弹出（记住打开前的相机，关闭时还原），同时 `body.modal` 让 `#stage` 直接 `display:none`：画布不是"画完再盖住"，而是**完全不渲染**，弹层期间零画布开销。
- 背景只留淡网格并压暗，点背景或 × 关闭；关闭后恢复画布并重绘一帧。
- 画布隐藏期间 `clientWidth` 会是 0，所以相机计算一律用 `DSRender.view()` 里缓存的尺寸，不要直接读 `cv.clientWidth`。
- 帧率不做任何节流（`requestAnimationFrame` 每帧都画），代价是静止时也在重绘；如果之后发现费电/风扇响，可以加回"静止 1 秒后停画"。
## 一个隐蔽的坑：隐藏的面板仍然是点击目标

`.panel` 关闭状态只用 `opacity:0` + `transform` 移出视野时，它依然**占据屏幕中央并接收鼠标事件**——表现为"图能看见但点不动、滚轮没反应"。

正确写法要同时给：`visibility:hidden` + `pointer-events:none`，打开时再切回。排查方法：在控制台跑
`document.elementFromPoint(innerWidth/2, innerHeight/2).id`，期望是 `stage`。
## 交互细节

- 拖动结点后**不会**触发选中/开面板（位移 > 6px 视为拖动）。
- 点面板外任意位置关闭答题层。
- 松手或拖动结束会重新激活布局，邻居会自己滑到新位置；开局也能看到图自己摊开（预热只跑 80 步）。
